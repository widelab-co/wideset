New `Shortcut` component shows the keyboard shortcut for an action, one `Shortcut.Key` per key (`⌘ ⇧ ⌥ ⌃` read by name, `↵ ↑ ↓ ← →` drawn as icons), in a `strong` cap or `weak` inline, with an `inverse` variant for dark surfaces such as Tooltip; the skills know when to use it.
