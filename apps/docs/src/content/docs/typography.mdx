Each `typography-*` class sets four things at once: size, line height, letter spacing and
weight. It never sets the font family: components inherit the font on `body`, so your brand
font applies to them too (see [Installation](/docs/installation#4-load-the-font)).

```tsx
<h1 className="typography-title-md">Settings</h1>
<p className="typography-body-md">Changes save automatically.</p>
```

Weights come from Figma and are not round numbers (`font-ws-medium` is 520, `font-ws-normal`
480). Load a variable font to see them as designed.
